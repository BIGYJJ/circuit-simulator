# 可视化电路模拟器 · 首个工作台切片

本项目是一个**本地优先的浏览器电路学习工作台**。它不把电路项目发送到服务器，而是在浏览器中保存版本化电路文档；默认入口提供可验证的理想 RC 瞬态实验，`/led` 提供 LED 非线性近似与故障挑战，`/divider` 则保留可自由搭建的线性直流分压器工作台。界面以用户提供的 FLUXLAB 参考图为直接视觉基准，使用深色工程网格、左侧实验/元件区、中心搭建区、右侧证据检查器和底部测量区，呈现“搭建—现象—解释”的完整路径。

## 当前能力

| 能力 | 当前实现 | 验证方式 |
| --- | --- | --- |
| 默认实验 | 5 V、10 kΩ、100 μF、开关与参考地构成的理想 RC 三态回路 | `τ = 1.0 s`；充电 `1τ` 时 `Vcap ≈ 3.1606 V`，放电 `1τ` 时 `Vcap ≈ 1.8394 V` |
| 瞬态回放 | 播放、暂停、单步、复位、模式切换和时间游标共用同一组预计算样本 | 画布读数、Vcap 曲线、支路电流、电容能量和功耗同步更新 |
| RC 画布编辑 | 可拖拽元件、移动元件、从端口吸附连线、选择/删除导线、撤销和重做 | 开放端口在工具栏与状态栏提示，允许先搭建再求解 |
| 可视化证据 | 网格画布、RC 符号、Vcap 读数、活动路径、示波器、时间显微镜与公式卡 | 曲线只绘制瞬态求解器返回的 501 个采样点 |
| 导出 | 可导出当前电路项目 JSON 与已求解的 RC 时间序列 CSV | CSV 包含时间、电容电压、支路电流与电容能量 |
| LED 实验室 | 位于 `/led`，以 5 V、330 Ω、2 V LED 建立常压降工作点近似 | 默认工作点约为 9.09 mA，位于教学目标 8–12 mA 内 |
| 非线性证据 | LED 压降、支路电流、LED/电阻功耗、发光估计与双通道测量 | 求解器明确标注为常压降教学近似，而非 SPICE 器件模型 |
| 故障与挑战 | 开路、短路、错误 68 Ω 限流与“调亮 LED”目标检查 | 故障会改变画布证据和诊断；完成状态保存到本地 |
| LED 导入导出 | 导出工作点 CSV、实验 JSON，并可导入包含 LED 元件的项目 JSON | 导出只包含已求解的数值或版本化项目事实 |
| 分压器编辑器 | 位于 `/divider`，支持拖拽放置、移动、端口吸附连线、删除导线与撤销重做 | 默认 9 V/1 kΩ/2 kΩ 电路求得 Vout = 6.000 V |
| 错误诊断 | 开关断开、RC 回路不完整、缺失元件、错误元件参数和分压器未接线端口 | 核心模型与两个求解器均覆盖典型错误分支 |
| 本地保存 | 文档采用带版本号的 JSON 格式保存在浏览器本地存储 | 刷新页面后可恢复有效的上次实验 |
| 工程质量 | 类型检查、Vitest 单元测试和生产构建 | 执行下方脚本即可重复验证 |

## 本地运行与验证

安装依赖后，以 `pnpm dev` 启动本地开发服务器。`pnpm test` 会验证电路文档、线性分压器、RC 充放电、LED 工作点/故障、导出和时间显微镜的典型与错误用例；`pnpm check` 执行 TypeScript 类型检查；`pnpm build` 生成生产构建。项目已配置 GitHub Actions 工作流，以便在推送或拉取请求时重复执行上述质量门禁。

| 命令 | 用途 |
| --- | --- |
| `pnpm dev` | 启动开发工作台 |
| `pnpm test` | 运行领域模型与求解器测试 |
| `pnpm check` | 运行 TypeScript 类型检查 |
| `pnpm build` | 执行生产构建 |

## 架构边界

电路事实由 `client/src/lib/circuit-model.ts` 保存，包含元件、端口、导线、格式版本和结构校验；线性 DC、RC 瞬态黄金基线和 LED 常压降工作点分别位于 `client/src/lib/circuit-solver.ts`、`client/src/lib/rc-charge-solver.ts` 和 `client/src/lib/led-solver.ts`；画布、示波器和证据检查器只投影模型和求解结果。这个分离使未来将求解器移入 Web Worker 或替换为 Rust/WASM 后端成为可能，且不会改变用户项目格式或画布编辑体验。

当前 RC 求解器刻意只保证一个清晰可验证的**理想单支路充电、保持和放电拓扑**，并以解析式作为黄金基线；LED 实验只保证固定正向压降、分段线性的教学近似；分压器编辑器则只保证线性 DC 分析。数值积分、多节点 RC 网络、二极管的指数 I–V、晶体管、数字逻辑、SPICE 兼容和云协作均属于后续增量；界面中与这些能力相关的入口会提示其尚未开放，而不会伪造数据或功能。

> 此工具用于学习与设计探索。仿真读数依赖简化模型，不能替代元器件数据手册、硬件测量或安全验证。
