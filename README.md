# 可视化电路模拟器 · 首个工作台切片

本项目是一个**本地优先的浏览器电路学习工作台**。首版不把电路项目发送到服务器，而是在浏览器中保存版本化电路文档，并提供一个可以验证的线性直流分压器实验。界面以用户提供的 FLUXLAB 参考图为直接视觉基准，使用深色工程网格、左侧元件库、中心搭建区、右侧检视器和底部测量区，呈现“搭建—现象—解释”的完整路径。

## 当前能力

| 能力 | 当前实现 | 验证方式 |
| --- | --- | --- |
| 默认实验 | 9 V 电源、1 kΩ 电阻、2 kΩ 电阻和参考地构成的串联分压器 | 输出节点理论值与求解结果均为 6.000 V |
| 参数实验 | 可选择 R1、R2 或 V1，输入数值、步进调整并应用参数 | 更新后重新运行，节点电压和功耗读数随之刷新 |
| 可视化证据 | 网格画布、电路符号、端口、选中态、Vout 读数浮层、DC 工作点读数 | 工作台画布与右侧“求解证据”同步呈现 |
| 错误诊断 | 缺少参考地、错误阻值、回路未闭合及非完整分压支路的可理解提示 | 核心求解器测试覆盖典型错误分支 |
| 本地保存 | 文档采用带版本号的 JSON 格式保存在浏览器本地存储 | 刷新页面后可恢复有效的上次实验 |
| 工程质量 | 类型检查、Vitest 单元测试和生产构建 | 执行下方脚本即可重复验证 |

## 本地运行与验证

安装依赖后，以 `pnpm dev` 启动本地开发服务器。`pnpm test` 会验证电路文档以及分压器求解器的典型和错误用例；`pnpm check` 执行 TypeScript 类型检查；`pnpm build` 生成生产构建。项目已配置 GitHub Actions 工作流，以便在推送或拉取请求时重复执行上述质量门禁。

| 命令 | 用途 |
| --- | --- |
| `pnpm dev` | 启动开发工作台 |
| `pnpm test` | 运行领域模型与求解器测试 |
| `pnpm check` | 运行 TypeScript 类型检查 |
| `pnpm build` | 执行生产构建 |

## 架构边界

电路事实由 `client/src/lib/circuit-model.ts` 保存，包含元件、端口、导线、格式版本和结构校验；线性 DC 求解由 `client/src/lib/circuit-solver.ts` 单独执行；`CircuitCanvas.tsx` 只负责把模型和结果投影为工作台图形。这个分离使未来将求解器移入 Web Worker 或替换为 Rust/WASM 后端成为可能，且不会改变用户项目格式或画布编辑体验。

当前求解器刻意只保证一个清晰可验证的分压器拓扑。RC 瞬态、示波器真实波形、拖放布线、二极管与晶体管、数字逻辑、时间显微镜、故障注入、SPICE 兼容和云协作均属于后续增量；界面中与这些能力相关的入口会提示其尚未开放，而不会伪造数据或功能。

> 此工具用于学习与设计探索。仿真读数依赖简化模型，不能替代元器件数据手册、硬件测量或安全验证。
